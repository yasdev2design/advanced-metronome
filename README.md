# 🎵 Metronome

A modern, responsive, and feature-rich web-based metronome designed for musicians, music students, producers, and anyone who wants precise tempo control.

Built with a clean user interface, smooth interactions, and a focus on accuracy, usability, and performance.

## ✨ Features

* 🎚️ **Precise BPM Control** — Easily adjust tempo with fine-grained control.
* ▶️ **Play / Pause** — Start and stop the metronome instantly.
* 🔢 **BPM Input** — Enter an exact tempo value manually.
* ➕➖ **Tempo Controls** — Quickly increase or decrease BPM.
* 🥁 **Visual Beat Indicator** — Clearly displays the current beat.
* 🔊 **Audio Beat Detection** — Provides audible metronome clicks.
* 🎼 **Time Signature Support** — Configure beats per measure.
* 🔥 **Accent Beat** — Emphasizes the first beat of each measure.
* ⌨️ **Keyboard Controls** — Control important functions without using the mouse.
* 📱 **Responsive Design** — Works smoothly across desktop, tablet, and mobile devices.
* 🌙 **Modern UI** — Clean interface designed for comfortable long-term use.
* ⚡ **Fast & Lightweight** — Minimal overhead and quick loading.
* ♿ **Accessible Controls** — Designed with usability and accessibility in mind.

## 🎼 Tempo

The metronome supports configurable BPM values, allowing you to practice everything from slow exercises to fast-paced musical passages.

**BPM** stands for **Beats Per Minute**.

For example:

|     BPM | Typical Use        |
| ------: | ------------------ |
|   40–60 | Very slow practice |
|   60–80 | Slow practice      |
|  80–120 | Moderate tempo     |
| 120–160 | Fast practice      |
|    160+ | Very fast practice |

These ranges are examples only; musicians can use any tempo appropriate for their practice.

## 🥁 Time Signatures

The metronome can be configured for different musical meters.

Common examples include:

* `2/4`
* `3/4`
* `4/4`
* `6/8`

The first beat of each measure can be accented to make the meter easier to follow.

## 🔊 Audio

The metronome uses browser audio capabilities to generate precise click sounds.

Modern browsers may require a user interaction before audio playback can begin. Simply pressing the **Play** button should initialize the audio context.
